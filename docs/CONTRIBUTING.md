# Contributing to Poker Game Collection

Thank you for your interest in contributing to this project! Here are some guidelines to help you get started.

## How to Contribute

### Reporting Bugs
- Check if the bug has already been reported in Issues
- Use a clear and descriptive title
- Describe the exact steps to reproduce the problem
- Provide specific examples and sample inputs
- Describe the behavior you observed and what you expected
- Include screenshots if applicable

### Suggesting Enhancements
- Use a clear and descriptive title
- Provide a detailed description of the suggested enhancement
- Explain why this enhancement would be useful
- List any similar features in other poker games

### Pull Requests
1. Fork the repository
2. Create a new branch (`git checkout -b feature/AmazingFeature`)
3. Make your changes
4. Test your changes thoroughly
5. Commit your changes (`git commit -m 'Add some AmazingFeature'`)
6. Push to the branch (`git push origin feature/AmazingFeature`)
7. Open a Pull Request

## Code Style Guidelines

### C++ Style
- Use 4 spaces for indentation (no tabs)
- Follow existing naming conventions:
  - `camelCase` for functions and variables
  - `PascalCase` for classes and structs
  - `UPPER_CASE` for constants
- Add comments for complex logic
- Keep functions focused and reasonably sized
- Use meaningful variable and function names

### File Organization
- Header files (.h): Declarations only
- Implementation files (.cpp): Function definitions
- Keep related functionality together in modules
- Include guards in all header files

### Documentation
- Document all public functions
- Explain non-obvious code with comments
- Update README.md when adding new features
- Update CHANGELOG.md with changes

## Testing
- Test all game scenarios before submitting
- Verify that all three games work correctly
- Check edge cases (single player, max players, etc.)
- Ensure no memory leaks or crashes

## Commit Message Guidelines
- Use present tense ("Add feature" not "Added feature")
- Use imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit first line to 72 characters
- Reference issues and pull requests when applicable

## Questions?
Feel free to open an issue for any questions about contributing.

Thank you for helping make this project better!
