# Changelog

## [1.0.0] - 07/12/2024

### Added
- Initial release with three poker game variants
- Texas Hold'em Poker with full betting system
- Two Five Hihi variant with voting mechanism
- Surprising Swap variant with card swapping
- Leaderboard and statistics tracking
- Sound effects and colored console output
- Modular code structure with separate header and implementation files

### Project Structure
- Split monolithic main.cpp into modular components
- Created separate header (.h) and implementation (.cpp) files
- Utils module for shared utility functions
- Individual modules for each game variant

### Documentation
- Added comprehensive README.md
- Created .gitignore for version control
- Added CMakeLists.txt for cross-platform building
- Included this CHANGELOG.md
